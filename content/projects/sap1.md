An 8-bit computer from scratch using logic gates and electronic components. Includes an instruction set with manual programming functions and core components such as a clock, ALU, registers, program counter, etc.

I built the SAP-1 because I wanted to challenge myself on working with only logic gates to create a functional system and to dive deeper into how computers work at a fundamental level, and what is most fundamental other than manipulating electricity itself?
