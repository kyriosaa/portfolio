Built an 8-bit computer from scratch using logic gates and electronic components. Includes an instruction set with manual programming functions. Includes core components such as a clock, ALU, registers, program counter, instruction decoder, and memory, all hand-wired on breadboards.

I built the SAP-1 because I wanted to challenge myself on working with only logic gates to create a functional system and to dive deeper into how computers work at a fundamental level, and what is most fundamental other than manipulating electricity itself?
